# 🍈 BLOX FRUITS AI

**An AI-Powered Next Generation Web App for Blox Fruits Players**

A comprehensive, interactive encyclopedia and AI-driven companion app for the popular Roblox game **Blox Fruits**. Powered by Claude AI, this application provides real-time strategies, tier lists, build recommendations, and complete game database access.

---

## ✨ Features

### 🤖 AI Chat Assistant
- Ask anything about Blox Fruits gameplay, strategies, and builds
- Get instant answers powered by Claude AI
- Context-aware responses for bosses, progression, and meta strategies
- YouTube video analysis for strategy extraction

### 📚 Complete Game Database
- **150+ Fruits** with detailed stats, abilities, and pricing
- **50+ Swords** with damage ratings and descriptions
- **6 Fighting Styles** with unique move sets
- **80+ Bosses** with level requirements and drops
- **Maps & Locations** across all three seas

### 🏆 Dynamic Tier Lists
- **PvP & PvE Rankings** for all fruits
- AI-powered meta analysis
- Real-time tier organization based on current patch
- Strategic insights for each tier

### ⚗️ Build Creator
- Custom build recommendations powered by AI
- Combine fruits, swords, and fighting styles
- Playstyle-specific optimization (PvP, PvE, Hybrid)
- Level-based progression suggestions

### 📰 News & Updates
- Latest patch notes and updates
- Event announcements
- AI-powered news search functionality
- Balance change analysis

### 🎨 Modern UI/UX
- Beautiful glassmorphism design with gradient accents
- Fully responsive (mobile, tablet, desktop)
- Smooth animations and transitions
- Dark theme optimized for extended gaming sessions
- Ocean-themed visual aesthetics

---

## 🛠️ Technology Stack

- **Frontend**: React.js with modern hooks
- **Styling**: Custom CSS with glassmorphism effects
- **AI Engine**: Anthropic Claude API (Claude Sonnet 4)
- **Storage**: Browser LocalStorage for API key management
- **Language**: JavaScript (JSX)
